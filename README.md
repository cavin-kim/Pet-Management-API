## Repository Description
Pet-Management-API is a RESTful Spring Boot API designed to help users manage their pets' information and daily activities. This project allows you to store details about your pets (e.g., name, species, age) and log their activities (e.g., feeding, walks, playtime). It also includes user authentication to ensure secure access to pet data.

Perfect for pet lovers and developers alike, this API provides a simple yet powerful way to organize and track your furry friends' lives. Whether you're building a personal pet diary or integrating it into a larger application, Pet-Management-API has you covered!

## Technologies Used
Backend Framework : Spring Boot
Database : H2 (for development), MySQL/PostgreSQL (for production)
Authentication : Spring Security + JWT
API Documentation : Swagger/OpenAPI
Build Tool : Maven or Gradle
